# 기존 하이브리드 실험 코드

- 브랜치: `exp/Hybrid-v1`
- 범위: 기존 타일 1차 실험의 Python 처리 코드
- 현재 3공종 T-Box 확장: 루트 README 및 `hybrid_multitrade/` 사용
- 환경: `hybrid-v1`. 루트 requirements는 현재 3공종 기준이며 과거 실험의 완전한 환경 잠금 파일은 아님
- 외부 소스·모델·입력 파일: 별도 준비
- 비공개 입력·원문 인용 보고서·가격·원시 결과·캐시·가중치: 업로드 제외
- 문서 기반 추출은 입력을 외부 API로 전송할 수 있으므로 비공개 자료 사용 전 별도 승인 필요
- 과거 A-Box exporter: 비공개 회차 정보 포함으로 공유 제외. `run_all.py`는 후보 판단 단계까지 실행
- 공유 범위: 소스 보관용. 새 clone 전체 재현 검증 미실시
