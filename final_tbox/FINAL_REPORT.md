세 공종에서 후보 51개와 직접 부모 51개를 검사했다. 2026-11-10 추가 감사에서 기존 후보 입력에 부모가 포함된 정답 누설을 발견해 해당 필드를 전부 제거했다. 현재 builder는 식별자·라벨·정의만으로 lexical/lifecycle 부모를 예측하며, 입력 manifest와 단위검사에서 부모 필드 부재 및 gold 비참조를 강제한다. 수정 전 정답 없는 기준선은 micro-F1 0.902였고, 공법 변형·측량·검사 앵커의 일반 규칙을 수정한 뒤 TP 51, FP 0, FN 0, micro-F1 1.0을 기록했다. 이는 같은 세 공종 gold를 보며 개발한 적합도이므로 독립 holdout 성능은 아니다. competency question 51/51과 오류 주입 대조군 9/9도 통과했다.

전체 생성·검증을 두 번 반복한 결과 세 공종의 Turtle/RDF/XML 해시와 모든 판정 fingerprint가 같아 `CONVERGED`로 종료됐다. 이 closed-loop는 릴리스 자가검증 절차이며 온라인 자기학습 모델을 추가한 것이 아니다.

### 추가 스트레스 검증

후속 검증에서는 builder와 validator를 매 회차 새 Python 프로세스로 실행해 10회 연속 검사했다. 10/10회가 모두 통과했고, 세 공종의 OWL/Turtle 6개 파일 해시와 전체 검사 fingerprint가 1회차와 완전히 동일했다. KCSC·국가법령정보센터의 공식 근거 URL 5개도 모두 HTTP 200으로 다시 확인했다. 상세 기록은 `reports/multitrade_stress_validation.json`에 있다.

후보 단위 적대적 검증도 추가했다. 51개 후보 각각에 대해 근거 출처 삭제 51건, 근거 조항 삭제 51건, 라벨 삭제 51건, 정의 삭제 51건, 직접 부모 오배치 51건을 검사했다. 비루트 후보의 공종 루트 연결 단절 48건과 공종별 A-Box·계층 순환·타 공종 namespace 혼입 각 3건을 더해 총 312건을 주입했으며 312/312를 모두 검출했다. 이 검사는 `run_final.py`의 필수 단계로 편입했다.

이 1.0 수치는 세 공식 기준에서 구축하고 규칙 개발에도 사용한 **경계가 정해진 내부 개발 벤치마크와의 일치율**이다. 정답 필드는 빌드 입력에서 제거됐지만 동일 gold를 보며 규칙을 보정했으므로 별도 현장 문서나 보지 않은 네 번째 공종에 대한 일반화 정확도 100%를 의미하지 않는다. 또한 gold는 현재 연구자가 기준 조항을 대조해 만든 것이므로, 독립 도메인 전문가 검토를 거치기 전에는 외부 검증 점수라고 부르지 않는다.

## 모델 성능 해석

현재 이용 가능한 보류 평가는 RC 부모 예측 4건뿐이다. Top-1 부모 정확도와 계층 micro-F1은 모두 0.50이고, Top-1 정확도의 95% Wilson 구간은 약 0.15~0.85다. 표본이 매우 작고 타일 확장 정답이 아니므로 “타일 T-Box가 잘 확장된다”는 일반 성능 근거로 사용할 수 없다.

반면 이번 입력 한 건에 대한 산출물 검증에서는 채택 후보 11개가 모두 최종 근거 식별자를 가졌고, 보류 후보 9개는 T-Box에 유입되지 않았다. 제공 자료로 작성한 내부 의미 기준에서는 precision·recall·F1·채택 부모 정확도가 모두 1.0이며 competency question 10개도 통과했다. 이 수치는 **이번 사례가 명시적인 최종 규칙과 일치한다**는 뜻이지, 독립 정답이나 새로운 현장에서의 정확도 100%를 뜻하지 않는다.

## 완료 기준

최종본은 클래스·속성·공리만 가진 T-Box여야 하며, seed 구조를 훼손하지 않고 채택 후보만 확장해야 한다. 두 직렬화가 같고, OWL 2 DL 프로파일을 만족하며, HermiT에서 일관되고 모든 명명 클래스가 만족 가능해야 한다. 또한 채택 후보는 문서 또는 WBS 근거 식별자를 가져야 한다.

## 중요한 해석 경계

기술 검증이 모두 통과해도 독립 전문가 정답 없이 자동확장 의미 정확도(precision/recall/F1)는 확정할 수 없다. 현재 저장된 RC 보류 평가는 4건뿐이고 타일 확장의 gold standard가 아니다. 따라서 최종 상태는 검증 파일의 `release_status`를 그대로 사용하며, 의미 평가가 비어 있으면 `TECHNICALLY_VALIDATED_SEMANTICALLY_PROVISIONAL`로 판정한다.

이는 실패를 숨기는 문구가 아니라 다음 두 질문을 분리한 결과다.

- “OWL 파일이 T-Box 전용이고 논리·구조적으로 유효한가?” — 자동 검증 가능
- “추가한 타일 개념과 직접 부모가 도메인 전문가 기준으로 정확한가?” — 독립 라벨셋 필요

따라서 현 상태는 배포 가능한 T-Box 파일, 재현 가능한 기술 검증, 제공 자료 기반 내부 의미검증까지 완료됐다. 논문에는 ‘내부 의미검증 완료’라고 표기할 수 있지만 ‘독립 전문가 정확도 검증 완료’라고 표기하면 안 된다.

## 재실행 감사

저장된 완료 산출물은 검증에 사용할 수 있다. 그러나 2026-10-29 현재 `nvidia-smi`가 GPU 드라이버와 통신하지 못하고, 현재 `requirements.txt`의 SHA-256이 원실험 환경 기록과 다르다. 완료 manifest 114개 중 문서 `test2/README.md` 1개도 기록 후 변경됐다. 따라서 Module1~5를 원자료부터 완전히 다시 실행했다는 주장은 하지 않는다. 세부 결과는 `reports/environment_audit.json`에 있다.

## Closed-loop 수렴

각 반복은 T-Box 직접 생성, OWLAPI/HermiT 검증, 오류 주입, 근거 대조, 내부 후보 판정, competency question, 환경 감사를 전부 다시 실행한다. 두 반복의 산출물 해시, 클래스 수, 검사 결과, 후보 confusion matrix, CQ 결과, 근거 수, 계층 지표가 모두 같아 2회차에서 수렴했다. 내부 의미 기준 파일은 빌드 입력 해시에 포함되지 않아 정답 파일을 읽고 온톨로지를 생성하는 누수도 차단했다.

## 의미평가 완료 방법

3개 공종은 `python final_tbox/prepare_multitrade_expert_review.py`로 51개 검토지를 만든 뒤 독립 전문가 2명과 판정자가 작성하고 `python final_tbox/score_multitrade_expert_review.py`로 채점한다. 현재 점수 상태는 `PENDING_EXPERT_ADJUDICATION`이다. 이 검토지는 생성 후보만 포함하므로 누락 개념에 대한 selection recall은 별도 누락 표본 없이는 계산하지 않는다.
