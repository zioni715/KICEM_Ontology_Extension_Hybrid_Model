# 하이브리드 T-Box 확장 모델 설명서

## 처리 구성

| 단계 | 역할 | 구현·모델 |
|---|---|---|
| 1. 추출·초기 스키마 | 근거에서 후보와 속성 생성 | 기존 OmEGa-inspired 어댑터, GPT-4o-mini |
| 2. 후보 부모 순위 | 상위 개념 후보 점수화 | TaxoPro, multilingual BERT·LoRA |
| 3. 개념 정합 | 기준 온톨로지와 동등성 검토 | MILA, multilingual E5·GPT |
| 4. 계층 확장 | 폭·깊이 방향 신규 후보 생성 | TaxoAdapt, Llama 3.1 8B |
| 5. 부모 선택·근거 검토 | 계보 순위·검색·의미·근거 검토 | TEMPORA·LOREx 어댑터, BERT·Llama·GPT |
| 6. 출력·검증 | 승인된 T-Box 직렬화와 논리 검사 | RDFLib, OWLAPI, HermiT |

- 기반: 기존 타일 실험 구현 재사용
- 구현 범위: API 추출·단일 GPU 어댑터 포함. 원 논문 전체 구현의 동일 재현은 아님

## 단일 공통 파이프라인

- 실행: `python hybrid_multitrade/run.py` 한 번으로 세 공종 처리.
- 구현: `hybrid_multitrade/pipeline/`의 공통 코드 한 벌만 사용.
- 공종명·식별자: `pipeline/configs/trades.json`에서 주입. 공종별 코드 생성·복제 없음.
- 공종마다 입력·캐시·체크포인트·결과만 분리하고 동일한 소스 해시를 기록.
- 통합 코드의 3공종 전체 실행 완료. 기존 후보별 결정 및 최종 OWL 그래프와 동일함을 확인.
- 회귀검사 20건 통과, 생략·실패·오류 0건.
- 단계별 프로세스 분리는 GPU 메모리 해제를 위한 실행 방식이며 별도 공종 모델 코드가 아님.
- 통합은 처리 코드의 통합을 의미. 세 공종 공동 학습이나 OWL 산출물 통합을 의미하지 않음.

## 공종별 적용

- 대상: 타일공사, 우수공, 유도등 설비공사.
- 고정: 모델 ID, 학습 epoch·학습률·seed·loss, 모듈 호출 순서.
- 변경: 공종명, 입력 데이터, 실행·출력 경로.
- 공통 파이프라인 소스와 설정의 해시는 각 실행의 `provenance.json`에 기록.
- 모델의 평가 정답은 입력하지 않음.
- 원본 실험 결과와 체크포인트는 수정하지 않음.

## 이번 재실험 입력

- 입력: [trade_candidates.json](../hybrid_multitrade/inputs/trade_candidates.json).
- 공종별 입력: 24·12·15건의 기준 기반 작업 설명.
- 출처와 조항: [WBS 근거표](../wbs/EVIDENCE.md).
- 비공개 기성서류를 외부 API로 보내지 않도록 세 공종 모두 정규화된 공개 기준 설명을 사용.
- 가격과 물량은 추정하지 않고 null로 전달.
- 원래 타일 기성서류 실험과는 입력 종류가 다르므로 동일 입력 조건의 재현이라고 보고하지 않음.

## 출력과 검증

- API·로컬 LLM의 원시 결과, 학습 기록, 체크포인트는 로컬 `.runs/unified/<공종>/`에 보관.
- 최종 출력은 클래스·상속·속성 선언·domain·range·근거 주석을 포함한 OWL·TTL.
- 현장·WBS 인스턴스, 개체 소속·관계, 물량·단가·실적값은 생성하지 않음.
- 명명 개체 선언뿐 아니라 암시적 클래스 소속 assertion과 일반 속성값 assertion도 차단.
- 계층 순환·순수 T-Box·직렬화·OWLAPI·HermiT 검사 통과 전에는 최종 산출물을 저장하지 않음.
- OWLAPI의 OWL 2 DL 프로파일 검사와 HermiT 일관성·명명 클래스 만족 가능성 검사 수행.
- 모델이 승인한 후보와 전문가가 검증한 후보를 동일하게 취급하지 않음.
- 전문가 정답이 없으므로 독립 의미 정확도·recall·F1은 아직 산출하지 않음.

- 순수 T-Box·비순환·직렬화 동등성·OWL 2 DL·HermiT 일관성/클래스 만족 가능성 검사 통과.

- 회귀검사: 공통 코드 실행, 공종 설정 분리, A-Box 차단, 실제 추론기 대조검사, 입력 인용·부모 공리·파일 해시 대조.
- 후보별 부모·인용·보류 사유: [결과 설명서](../hybrid_multitrade/RESULTS.md) 및 공종별 JSON.
