# T-Box 자동확장 모델 카드

## 목적과 범위

기존 RC OWL 2 T-Box의 공통 문서·비용 구조를 재사용하고, 타일공사 문서와 WBS에서 생성·검토한 후보를 근거 기반으로 삽입하여 독립 타일공사 T-Box를 생성한다. A-Box 개체와 사실 assertion은 생성하지 않는다.

입력은 RC seed T-Box, 초기 타일 스키마, 후보별 판정, 최종 근거 감사 결과다. 출력은 의미적으로 동일한 `outputs/tile_tbox_final.ttl`과 `outputs/tile_tbox_final.owl`이다.

## 처리 구성

1. OmEGa 착안 문서 추출과 초기 후보 구성
2. TaxoPro 부모 후보 순위화
3. MILA 공통 의미 역할 대응
4. TaxoAdapt 너비·깊이 후보 생성
5. TEMPORA/LOREx 착안 경로·근거 검토
6. 명시적 근거 규칙과 역할 제약 적용
7. seed에서 직접 최종 T-Box 생성
8. closed-loop 릴리스 검증

closed-loop는 새로운 학습 모델이 아니다. 같은 신뢰 입력에서 산출물을 재생성하고 기술·근거·의미 검사를 반복하여 두 회 연속 동일한 결과가 나오는지 확인하는 릴리스 절차다.

## 성능 해석

내부 기준에 대한 precision·recall·F1과 채택 부모 정확도는 모두 1.0이다. 이 기준은 제공된 동일 자료와 최종 명시 규칙으로 만든 내부 판정이므로 독립 일반화 성능이 아니다. 저장된 RC 부모 보류 평가는 4건 중 2건 정답이고 계층 micro-F1은 0.50이다. 엄격 LOREx 경로 판정과 최종 채택의 일치는 8/11이다.

따라서 이 릴리스가 뒷받침하는 주장은 “이번 입력에서 근거 추적 가능하고 논리적으로 유효한 T-Box를 안정적으로 생성했다”이다. 다른 현장·공종에서의 일반 정확도와 독립 전문가 수준 성능은 뒷받침하지 않는다.
