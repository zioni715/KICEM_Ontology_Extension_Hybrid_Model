# 3개 공종 WBS 근거 및 조항 추적표

- 이 검증에서 말하는 WBS는 특정 현장의 공정표를 복제한 것이 아니라, 국가 기준의 시공·설치·검사 요구사항을 T-Box 확장 후보로 사용할 수 있도록 작업 단위로 정규화한 **연구용 기준 WBS**다. 아래 `WBS ID`는 추적 편의를 위한 프로젝트 내부 식별자이며 KCS·NFPC·NFTC가 부여한 공식 분류번호가 아니다.

- 각 후보의 기계 판독 가능한 라벨·정의·근거 조항은 [trade_candidates.json](../hybrid_multitrade/inputs/trade_candidates.json)에 기록한다. 후보 입력에는 직접 부모 정답을 넣지 않는다.

## 건축-타일공사

- 주 기준: KCS 41 48 01 「타일공사」, 시행 2024-01-26
- 적용 범위: 3.1 일반사항, 3.2 벽타일, 3.3 바닥타일, 3.4 천장, 3.5 보양·청소, 3.6 검사
- 기준 기반 입력: 24건. 하이브리드 모델의 생성 클래스 수는 실험 완료 후 집계.
- 원문: <https://www.kcsc.re.kr/standardCode/viewer/KCS%2041%2048%2001%3A2024-01-26>

## T-Box 적용 및 검증 경계

- 기준의 목차를 그대로 `subClassOf`로 복사하지 않고 “A는 B의 한 종류인가”가 성립하는 작업유형 관계만 직접 부모로 사용한다.
- 입력 후보에는 `source_id`와 `section`을 기록하고 출처·조항 누락 여부를 검사한다.
- 공종별 입력 WBS는 근거로 제공하며, 생성 계층을 미리 정답으로 고정하지 않는다.
- 위치·층·공구·물량·일정·실적은 현장 인스턴스인 A-Box 정보이므로 T-Box 산출물에 넣지 않았다.
- 조항 추적 정보는 입력 설명의 출처 기록이다. 하이브리드 결과의 OWL 논리·구조 검증은 완료했으며, 독립 실무전문가의 의미 판정은 미실시다. [실행 결과](../hybrid_multitrade/RESULTS.md) 참고.
